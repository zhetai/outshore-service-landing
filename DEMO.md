## Title

**Offshore Evidence-Chain Technical Service Landing Page**

## Summary (English — paste into Upwork)

I built a single-file, dependency-free service page for an independent technical
practice that helps Hong Kong companies prepare offshore-exemption evidence chains
*before* handing material to a licensed tax adviser.

The page turns a vague service into a priced, scoped offer: four service lines
(technical interpretation, structural diagnosis, custom archive design, and a capped
hourly retainer), a five-step in-platform delivery protocol, an explicit in-scope /
out-of-scope boundary, contract safeguards, and eight clarifications written in plain
language. Everything is delivered inside Upwork — no off-platform contact, no side
payments.

The whole site is one HTML file with inline CSS and JavaScript: no build step, no
frameworks, no trackers, no external requests. It is responsive from mobile to
desktop, keyboard friendly, and respects `prefers-reduced-motion`.

**What the client gets:** a page that answers "what exactly am I buying?" before the
first message, and keeps the compliance line unambiguous throughout.
